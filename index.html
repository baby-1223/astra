Features

调试一个接口需要的，基本都在

没有账号体系，没有云同步，没有把请求发往第三方。打开就能用。

HTTP / REST

方法、Params、Headers、Cookie、多种 Body、代理与客户端证书，覆盖日常接口调试。

长连接与协议

WebSocket、SSE 实时流、GraphQL、gRPC-Web，响应格式自动识别。

集合与环境

集合/文件夹脚本继承、多环境变量、变量补全，接口之间可串联。

Mock 与抓包

本地 Mock 路由快速伪造响应；桌面端提供 HTTPS 抓包，把真实流量存成请求。

Spring 深度集成

插件解析 Controller、泛型 DTO、record、multipart 与父类路径，生成可直接发送的请求。

数据留在本地

工作区就是一个 JSON 文件，自动保留备份；敏感凭据存入系统凭据库，不落明文。

Getting started

三步开始

下载后不需要注册账号，直接新建请求或打开已有集合。

桌面端

  1. Windows：解压后保留同目录的 data\ 与 DLL，运行 Astra.exe。
  2. macOS：解压后把 Astra 拖入「应用程序」。首次打开若被系统拦截，右键选择「打开」。
  3. 新建请求，或从 Postman / Insomnia / OpenAPI / .http 导入现有集合。
macOS 如仍提示来源不明，可执行：xattr -dr com.apple.quarantine /Applications/Astra.app

IDEA 插件

  1. 打开 Settings → Plugins → Marketplace，搜索 Astra 并安装（或直接访问 插件主页）。
  2. 也可以从 GitHub Releases 下载 zip，在 ⚙ → Install Plugin from Disk… 中安装。
  3. 重启 IDE，在 Spring Controller 上右键选择 Generate Astra Requests。
插件也会自动读取项目里的 application.yml，把端口、context-path 与变量带入环境。
